Installation

npm
npm install @dgrammatiko/formally
CDN
<script type="module">
  import { Formally } from "https://cdn.jsdelivr.net/npm/@dgrammatiko/formally@latest/dist/formally.esm.min.js";
</script>

Or download the latest release from GitHub Releases and include dist/formally.iife.min.js (IIFE) or dist/formally.esm.min.js (ES module).

Quick start

Forms with class validate are initialized automatically when you load form-validator.js. 

<script type="module" src="dist/form-validator.esm.min.js"></script>

<form class="validate" data-live-check="true">
  <label for="email">Email</label>
  <input type="email" name="email" required>

  <label for="password">Password</label>
  <input type="password" name="password" required minlength="8">

  <button type="submit">Submit</button>
</form>

Manual initialization

<script type="module">
  import { Formally } from "./dist/formally.esm.min.js";

  const form = document.querySelector("form");
  const validator = new Formally(form);

  if (validator.isValid()) {
    console.log("Form is valid");
  }

  validator.dispose();
</script>

Form options

Options are read from data-* attributes on the <form> element.

Attribute Default Description
data-valid-class is-valid CSS class added to valid fields
data-invalid-class is-invalid CSS class added to invalid fields
data-live-check false Set "true" to validate on every keystroke
novalidate — If present, Formally skips the form entirely 
<form class="validate"
      data-valid-class="is-valid"
      data-invalid-class="is-invalid"
      data-live-check="true">
  ...
</form>

Field validation

Formally uses standard HTML5 validation attributes (required, min, max, minlength, maxlength, pattern, type, step). Custom error messages come from data-* attributes matching the validity state:

Data attribute Validity state Triggered when
data-value-missing valueMissing Field is empty but required
data-type-mismatch typeMismatch type="email"/"url" value is malformed
data-pattern-mismatch patternMismatch Value doesn't match pattern
data-too-long tooLong Value exceeds maxlength
data-too-short tooShort Value is below minlength
data-range-underflow rangeUnderflow Value below min
data-range-overflow rangeOverflow Value above max
data-step-mismatch stepMismatch Value doesn't fit step
data-bad-input badInput Value can't be converted (e.g. non-numeric type="number") 
<input type="email"
       name="email"
       required
       data-value-missing="Please enter your email"
       data-type-mismatch="That doesn't look like a valid email">

API

new Formally(form)

Creates a validator instance for the given <form>. Throws if not an HTMLFormElement. No-op if the form has novalidate.

formally.isValid() → boolean

Validates all registered fields. Returns true if the form is valid. Invalid fields are marked and the first invalid field is focused.

formally.dispose()

Removes all event listeners, disconnects the MutationObserver, and clears tracked elements. Call when the form is removed from the DOM.

formally.elementsForValidation

Array of form elements currently tracked for validation.

Dynamic fields

Formally observes the form with a MutationObserver. Fields added after initialization are automatically picked up; fields removed are automatically unwound (listeners removed) to prevent memory leaks.

j-formally (Joomla)

j-formally.js extends Formally for Joomla. It adds field handlers (username, password, email, numeric), custom validators, and Joomla message rendering via Joomla.Text._() and Joomla.renderMessages(). 

<script type="module">
  import { JFormally } from "./dist/j-formally.esm.min.js";
  window.JFormally = JFormally;
</script>

<form id="jform" class="form-validate">
  <input type="text" name="username" class="required validate-username" required>
  <input type="password" name="password" class="required validate-password" required>
  <input type="email" name="email" class="required validate-email" required>
  <button type="submit" class="validate">Submit</button>
</form>

<script>
  const form = document.getElementById("jform");
  const jf = new JFormally(form);
  jf.custom = { alwaysFail: { exec: () => false } };
</script>
  • setHandler(name, fn, enabled) — register a field validation handler
  • custom getter/setter — custom validators ({ exec } objects)
  • Bootstrap-style classes: form-control-success, form-control-danger, has-success, has-danger
